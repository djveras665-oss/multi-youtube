# Vários vídeos do YouTube ao mesmo tempo

Site de um arquivo só (`index.html`) para assistir vários vídeos do YouTube simultaneamente.

- Cole o link de um vídeo ou playlist e toque em **Adicionar**.
- **Iniciar todos** começa todos os vídeos de uma vez (sem som; use **Ativar som de todos**).
- Escolha 1, 2 ou 3 colunas, ou deixe em Auto.
- **Entrar no YouTube** abre o login do YouTube em outra aba.
- Cada vídeo tem um link **Abrir no YouTube** como alternativa.

## Publicar no GitHub Pages

1. Envie `index.html` para a raiz de um repositório público.
2. Em Settings > Pages, escolha "Deploy from a branch", branch `main`, pasta `/ (root)`.
3. O endereço será `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.
